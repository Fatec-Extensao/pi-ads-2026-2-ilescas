Objetivo 🎯

O propósito central do projeto é fornecer uma ferramenta tecnológica capaz de estruturar, aplicar e analisar pesquisas institucionais de forma totalmente organizada, segura e anônima.

O desenvolvimento deste software está contextualizado dentro de uma abordagem prática de engenharia de software. Ele engloba desde o levantamento e análise de requisitos até a modelagem de dados, implementação das interfaces web orientadas à usabilidade, mecanismos rigorosos de segurança da informação e a consolidação de dados em relatórios analíticos.

O escopo define-se pela criação de uma plataforma centralizada voltada para Gestores Educacionais, atuando como administradores do sistema , e para as categorias de respondentes, inicialmente representadas por Alunos e Professores. A solução proposta visa mitigar os desafios comuns em coletas de dados institucionais — como o retrabalho na tabulação e o risco de quebra de confidencialidade — por meio de três pilares fundamentais:

  • Gerenciamento Flexível: Permitir que administradores configurem pesquisas temporais e customizem questionários específicos de acordo com a categoria do participante.
  • Anonimato Garantido: Utilizar um modelo disruptivo de autenticação baseado em lotes de senhas aleatórias e de uso único. Isso desvincula completamente a identidade civil do respondente de suas respostas armazenadas.
  • Inteligência de Dados: Transformar as respostas brutas coletadas em informações visuais acionáveis através de dashboards de monitoramento em tempo real e relatórios estatísticos exportáveis.

Visão Geral 💡;

O projeto consiste no desenvolvimento de um Sistema Web para Gestão de Pesquisas por Questionário, concebido para automatizar o ciclo completo de pesquisas institucionais — desde a criação até a análise de resultados — com foco rigoroso na segurança e no anonimato dos participantes.

Principais Usuários

  • Gestores Educacionais (Perfil administrador)
  • Alunos (Perfil respondente)
  • Professores (Perfil respondente)

Visão de Produto e Escopo 🔎

O Sistema Web para Gestão de Pesquisas por Questionário é uma solução de software voltada para o ambiente institucional de ensino. O produto posiciona-se como uma plataforma web integrada de duas frentes:

  • Uma interface de gestão restrita a administradores (Gestores Educacionais), dedicada ao controle, parametrização e monitoramento analítico das pesquisas. organização por categorias;
  • Uma interface pública, simples e responsiva para os respondentes (Alunos e Professores), com foco exclusivo na coleta de dados com garantia de anonimato.

Visando

  • análise de resultados;
  • Facilidade de uso;
  • Anonimato para os usuários.

Os pilares fundamentais do software centram-se na facilidade de uso da plataforma e na garantia de anonimato absoluto para os usuários , assegurada por meio de senhas de acesso de uso único que desvinculam a identidade do participante de suas respostas , culminando em uma posterior análise de resultados automatizada para a gestão.
